# RegRag frontend

React + TypeScript app, scaffolded with Vite.

## Stack

- Vite + React + TypeScript
- TanStack Router / TanStack Query
- Tailwind CSS v4 + shadcn/ui
- Biome (lint/format)
- Vitest + Testing Library

## Scripts

- `pnpm dev` — start the dev server
- `pnpm build` — type-check and build for production
- `pnpm lint` — check formatting/lint with Biome
- `pnpm check` — check and auto-fix with Biome
- `pnpm test` — run tests in watch mode
- `pnpm test:run` — run tests once
- `pnpm generate-api` — regenerate `src/api/schema.ts` from the backend OpenAPI schema
